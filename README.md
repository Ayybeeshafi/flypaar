#  FlyPaar

Find trusted travel companions for elderly parents and first-time student travelers.

**Website:** [flypaar.com](https://flypaar.com)

## What is FlyPaar?

When your elderly parent or young student travels alone for the first time, it can be stressful. FlyPaar connects them with willing companions already on the same flight.

- **Post a trip** — share your flight details and whether you can help or need a companion
- **Search** — find travelers on the same route and date
- **Connect** — send a connection request, the traveler gets your details via email

## Privacy

- Personal information (email, phone, last name) is **never shown publicly**
- Contact details are shared **only via email** when someone sends a connection request
- Trip posts require **email verification** before going live

## Tech Stack

- **Framework:** Next.js (React)
- **Database:** Supabase (PostgreSQL)
- **Email:** Resend
- **Hosting:** Vercel
- **Styling:** Tailwind CSS
